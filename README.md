# shashwat6singh.github.io

Personal site, served by GitHub Pages at **https://shashwat6singh.github.io**.

Static HTML with no build step and no runtime dependencies. Editing `index.html`
and pushing to `main` is the whole deploy.

```
index.html   the page
assets/      figures pulled from the project repos, and the CV
```

The figures in `assets/` are copies of output committed in
[ma-homelessness-trend-break](https://github.com/shashwat6singh/ma-homelessness-trend-break),
[house-2026-forecast](https://github.com/shashwat6singh/house-2026-forecast) and
[nyc-311-service-delivery](https://github.com/shashwat6singh/nyc-311-service-delivery).
Regenerate them there, then copy across.
